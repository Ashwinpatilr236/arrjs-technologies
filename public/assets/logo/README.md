# ARRJS Technologies - Logo Directory / लोगो फ़ोल्डर

Aap apna logo file is folder me rkh sakte hain:
`public/assets/logo/`

## Available / Recommended Files:
1. `logo.png` or `logo.svg` -> Header aur Footer me main logo ke liye.
2. `logo-dark.png` -> Dark backgrounds / Footer ke liye optional white/light version.
3. `favicon.ico` or `favicon.svg` -> Browser tab icon ke liye.

## How to Change Logo / लोगो केसे बदले:
- Apne logo image (PNG or SVG format) ko is folder me drag-and-drop karein (`public/assets/logo/logo.png`).
- Direct URL: `/assets/logo/logo.png` or `/assets/logo/logo.svg`
- Website automatically aapke nayi logo image ko Header aur Footer me dikhayegi!
